ТЗ на изображения для hero-мозаики — АЭП
==========================================

СТРУКТУРА ПАПОК
heropict/1, heropict/2, heropict/3 — три независимых набора.
При каждом заходе на сайт показывается один из наборов по очереди
(1 → 2 → 3 → 1...), чтобы у постоянных посетителей мозаика не повторялась.

ФАЙЛЫ
- Формат: JPG (или WebP)
- Имена файлов: 1.jpg, 2.jpg, 3.jpg ... по порядку, без пробелов
- Размер холста: строго квадрат, 800×800 px (минимум 600×600)
- Вес файла: до 200 КБ каждый (сожмите перед загрузкой)
- Количество на набор: минимум 16, оптимально 24 файла
  (если положите меньше — скрипт зациклит имеющиеся, это не сломает сайт)

СОДЕРЖАНИЕ КАДРА
- Это фрагмент ("деталь") картины о Петербурге, не превью всей композиции
- Ориентир — примерно 10% площади оригинала: кусок неба, воды, фасада,
  мазки, фактура, цветовое пятно
- Специально избегайте кадров с лицами, подписью художника, четким
  узнаваемым сюжетным центром — задача мозаики дать фактуру и настроение,
  а не показать "мини-версию" картины
- Кадры внутри одного набора должны быть визуально разнообразны по тону
  (не все 24 квадрата в одной гамме), чтобы мозаика "дышала"

ЦВЕТ
- Цвет и яркость оригинала не трогаем, тонирование делает сайт
  автоматически (полупрозрачная индиго-подложка поверх мозаики)
- Не затемняйте и не осветляйте кадры вручную заранее
